# Цифровой университет

Практическая работа №1 по дисциплине «Технологии разработки программного обеспечения».

## Описание

Семантическая HTML-страница конференции с навигацией, карточками направлений,
таблицей расписания и формой регистрации. Стилизация выполнена на чистом CSS с
использованием Flexbox и адаптивной вёрстки.

## Технологии

- HTML5
- CSS3
- Git

## Структура проекта

```
tpro-pr01-student/
├── index.html          # главная страница
├── css/
│   └── styles.css      # стили
├── data/
│   ├── content.csv     # данные о направлениях
│   └── navigation.json # данные навигации
└── assets/
    ├── logo.svg        # логотип
    └── cover.svg       # обложка
```

## Запуск

1. Клонируйте репозиторий:

git clone https://github.com/i-GeKa-i/tpro-pr01-student.git


2. Откройте файл `index.html` в браузере.

Или используйте расширение Live Server в VS Code.
